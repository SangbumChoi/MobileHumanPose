This static demo runs the MobileHumanPose (LpNet) model exported to ONNX. For simplicity it assumes a single, roughly-centered person (center-square crop — no in-browser person detector). The bundled weights come from the pipeline's small, CPU-trained, auto-labeled demo run, so predictions are approximate. The Gradio app in the repo includes a person detector and multi-person support.
